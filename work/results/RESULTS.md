原始双端 FASTQ → 固定重叠合并 `window = R1[:250] + revcomp(R2)[145:250]`（扩增子 = ref[175:530] = 355nt，锚点 `AAAGCGTGCTGA`@175）→ 重建全长 612nt（`prefix175 + window + suffix82`）→ 翻译 204aa → 对 WT 找突变 → 定位可变位点 → 逐轮矩阵。

## 关键结果

### 1. 17 个设计位点被精确还原（有明显断层）
变体数排序前 17 位点 vs 第 18 位：67k–148k **骤降到** 32k。
**17 位点 = N66, V69, Y75, E94, Y102, A107, V111, I125, I128, Y129, A133, Y159, S161, F163, Q164, W169, P170**（编号对 204aa WT）。
每位点替换谱是特定几种氨基酸（如 E94→L/A/V/Q、Y159→F/W、A107→V/I、W169→L/V、S161→A、F163→M）→ 确为**设计的简并库**。

### 2. 这是一个高阶组合库，不是单点扫描 ⚠️（决定建模路线）
- **WT（0 突变）和单突变体完全不存在**；突变阶数分布集中在 **9–10 / 17**（最少 2）。
- 含义：**一阶效应无法直接测得**，所有突变都嵌在高阶背景里 → 回归/加性模型天然吃力，**上位感知 / 潜空间 / 可达路径推理**才对路。这直接坐实了 `BIO_DIRECTION`/`METHODOLOGY` 的立论。

### 3. 适应度（稳健指标）
- 定义：各变体 `log2(逐轮频率)` 对 round1–5 的**加权线性斜率**（斜率>0 = 随筛选轮次富集 = DNA 结合更好）。
- 干净变体（突变⊆17位点、无终止子）**109,134** 个；可靠子集（sum_count≥50）**6,840** 个。
- 位点倾向（`fig2`）：**P170、V111 强烈保守（突变有害）**；**S161→A、F163→M、Y102、A107、aa128/159/169 倾向突变**；E94 位点特异（E94A 有利、E94V/Q/L 有害）。
- PCA 2D 仅解释 **16.1%** 方差 → 景观高维、非线性、rugged（`fig3`）。
- 位点共现相关（`fig4`）给出上位线索（哪些位点突变倾向共同出现）。
