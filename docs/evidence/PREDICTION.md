# Prediction and recommender

## Status

The v4/v5 systems are exploratory candidate rankers using sequence, structure, allostery, pocket proximity, and ligand-group priors.

They are not established ligand-specific predictors. Cross-bile-acid generalization is not established, target-specific prediction is not established, and prospective validation has not yet been performed.

## Correct use

Use rankings to select hypotheses for experiments, not as confirmed activity predictions.
