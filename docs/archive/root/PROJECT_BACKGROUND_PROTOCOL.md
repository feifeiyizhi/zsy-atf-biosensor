## 0. v2 策略修订（2026-09-11，最新，覆盖 §2.3/§6/§7）

### 0.1 应用定位：合成生物学元件
这个 aTF 是一个**小分子诱导的基因表达开关**（chemogenetic switch）——用常见小分子操纵基因表达的合成生物学元件。用途：研究细胞工作机制、设计医疗用途细胞（如肿瘤治疗中，工程细胞响应疾病相关代谢物触发治疗输出）。
- 工程目标：**可编程的、响应特定小分子的 aTF 开关**，要求 ON/OFF 平衡、动态范围可调、配体特异性可控。
- 这把"合适 DNA 结合强度"说清：开关需无配体时结合 DNA（抑制）、配体结合后释放 DNA（去抑制）→ "合适强度"=平衡的动态范围，不是越强越好。

### 0.2 实验策略：由"直接双向"改为"顺序两步"（双向太复杂）
原 §2.3 的"同时双向筛选"放弃，改为**顺序两步**：
1. **先定下合适 DNA 结合强度的变体面板**：从负筛景观（338lib1-5）选一组 DNA 结合分层（强/中/弱但功能）的变体。**已产出**：`work/results/dnabinding_variant_panel.csv`（20 个，跨 5 档适应度）。
2. **逐个小分子筛选**：对每个面板变体，测各胆酸小分子对其 DNA 结合的别构调节（开关响应曲线）。
3. **AI 分析**：基于结构 + 结构动态，建模别构调节机制，预测新小分子的响应变体。

### 0.3 建模必须基于结构（别构/远程）
- aTF 是**别构调节**：小分子结合位点（C 端 LBD 口袋）与 DNA 互作位点（N 端 HTH）**离得远，远程耦合**——不能只做序列/嵌入回归。
- 17 个设计位点**全部落在 LBD（66–170），无一直接在 HTH DBD（~9–45）**→ 文库通过 LBD 构象**别构地**调节 DNA 结合，而非直接改 DNA 结合螺旋。这正是"远程作用"的结构证据。
- 需要：蛋白结构（WT + 关键变体）+ 结构动态（MD / 构象系综）+ 别构通信网络分析。**预测以结构为基**（结构条件模型 / 几何深度学习 / 结构网络）。

### 0.4 既有 CDCA/PCA 数据的重定位
原"直接双向筛选"产出的胆酸克隆数据，现重定位为**参考/ground-truth**：真实"配体响应变体"，用于校验结构模型预测的别构效应（Q164R 已知是 PCA 响应开关突变，在 LBD 口袋边）。

### 0.5 结构工具现状
- 无 GPU；`torch`+`esm` 包在；联网可到 AlphaFold DB / PDB。
- 结构获取优先级：① 查 PDB TetR 同源模板做同源建模；② 必要时 ESMFold（CPU 跑 204aa 偏重，单独起）；③ AlphaFold DB 取相近序列结构。

## 2. 蛋白与实验体系

### 2.1 蛋白
- **野生型**：204 aa（掐头去尾功能域 ~202 aa），TetR-family regulator (TFR)。
  - N 端 ~aa9–45：**HTH DNA 结合结构域**。
  - C 端：**配体（小分子）结合 / 效应结构域**。
  - 双属性天然对应实验的"DNA 结合能力 + 小分子响应能力"双轴。
- WT 蛋白（203 aa 去末终止子）：
  `MQKKLTRSQQKHLDIINAAKEEFIEFGFLAANMDRITSSAEVSKRTLYRHFESKEVLFESVLTIINDSVNESISYHFDPNKSTEEQLTEIAYKEIDVLYKTYGIALARTIVMEFLRQPEMAKTLIQNIYSIRAITQWFRSAIEAKRLKDADPKLMTDVYVSLFQGLFFWPQVMHLDLEPHGEELSQKIETLTTIFLQSYGVAE`

### 2.2 设计位点
- 基于 **17 个位点**的简并饱和突变随机库。17 位点（对 204aa WT 编号，已从数据精确还原）：
  **N66 · V69 · Y75 · E94 · Y102 · A107 · V111 · I125 · I128 · Y129 · A133 · Y159 · S161 · F163 · Q164 · W169 · P170**
- 每位点替换谱为特定几种氨基酸（如 E94→L/A/V/Q、Y159→F/W、A107→V/I、S161→A、F163→M、Q164→L）→ 简并密码子设计，非全随机。
- 替换谱主要落在配体结合结构域，部分在 HTH 附近。

### 2.3 两套进化实验（同一蛋白，两条选择轴）

| | 实验 A：DNA 结合负筛 | 实验 B：胆酸响应双向筛选 |
|---|---|---|
| 起点 | **完全随机库**（lib0）| 同一蛋白（含 R116Q 骨架）|
| 选择轴 | DNA 结合（结合差的留不下来 → 正向保留 DNA 结合）| **双向**：保留 DNA 结合 + 优化对目标小分子的响应 |
| 轮次/靶点 | 5 轮（lib1→lib5）| 7 个胆酸靶点：CDCA / TK-LCA / PCA / 23K-CDCA / LCA / LLDCA |

> 胆酸家族靶点：CDCA=鹅脱氧胆酸、LCA=石胆酸、23K-CDCA=23-酮-CDCA、TK-LCA、LLDCA 为相关衍生物——"相似但不同家族小分子"。

## 4. 数据处理 Protocol

### Protocol A：338lib NGS → 17 位点负筛景观
脚本 `work/build_landscape.py`（纯 Python，无需 bowtie2）。43 秒跑完全 5 lib。
1. **合并重建**：`window = R1[:250] + revcomp(R2)[145:250]`（355nt）；全长基因 = `prefix175 + window + suffix82`（612nt）。
2. **翻译** → 204aa；对 WT 找突变。
3. **定位可变位点**：变体数断层锁定 17 位点（前 17 位 6.7万–14.8万，第 18 位骤降 3.2万）。
4. **逐轮矩阵**：每变体 × 5 轮 count/pct。
5. **适应度**：`log2(逐轮频率)` 对 round1–5 的加权线性斜率（斜率>0 = 随轮次富集 = DNA 结合更好）。
6. **干净子集**：突变⊆17 位点、无终止子；可靠子集 sum_count≥50。

### Protocol B：胆酸纳米孔 pool → 逐靶点突变分布
脚本 `work/per_target_landscape.py`。
1. **每条 read**：锚点 `ATGCAGAAAA` 双向定位基因区 → 612bp → 翻译。
2. **过滤**：移码/含终止子/长度不符的 read 丢弃（纳米孔 indel 噪声）。
3. **蛋白级 diff**：对 ALT 密码子 WT 蛋白，每位点 AA 调用。
4. **频率化**（压纳米孔噪声）：每位点非-WT 比例；显著阈值 ≥10%。
5. **17 位点基因型分布** + 完整突变组合分布。

### Protocol C：交叉（胆酸赢家 × 负筛景观）
1. 胆酸每靶点 top 17 位点基因型，查 338lib 景观表 → 是否在设计空间内 + DNA 结合适应度。
2. 共享/特异突变（除骨架 R116Q）。
3. 多效位点识别（同时是负筛设计位 + 胆酸定义位）。

## 5. 已得结果（截至 2026-09-11）

### 实验 A 负筛景观（`work/results/`）
- 干净变体 109,134；可靠子集 6,840。WT/单突变**不存在**，阶数集中 9–10/17 → **高阶组合库**。
- 位点倾向：P170、V111 强烈保守；S161→A、F163→M 倾向突变；E94 位点特异。
- PCA 2D 仅解释 16.1% → 景观高维 rugged。

### 实验 B 胆酸分布（`work/results/per_target/`）
- **R116Q 两靶点 100% 固定** = 骨架起点自带（非筛选驱动）。
- **PCA 固定 Q164R(99.6%)**（17 设计位之一）；CDCA 在 17 位点 80% 回变 WT，Q164R 仅 16% + 非设计区 I73N(26%)。
- 共享(除骨架)=∅；CDCA 特异 I73N；PCA 特异 L177S。

### 交叉（关键发现）
- 胆酸赢家的 17 位点基因型**全部不在 338lib 负筛景观内**：负筛是 9–10 突变高阶库（无 WT/单突变），胆酸赢家是 WT/单突变基因型。
- **Q164R 在 338lib 仅 5/109k**（负筛 164 位点设计 L/Q/K，R 几乎未采样）→ PCA 却固定了它 → **进化找到了景观外的解**。
- **Q164 = 多效位点**：既 DNA 结合负筛设计位，又 PCA 胆酸响应定义位 → 跨景观锚点。
- **负筛景观与胆酸选择在序列空间几乎不相交** → 两套是**互补的两张景观**，不能在一张图直接交叉。

## 6. 科学问题与方法主张

### 6.1 核心主张（GraphWalks 迁移，论文 ML 新意）
进化 = **受上位效应约束的可达路径推理**，而非回归。用**可验证过程监督**（程序 checker 逐跳查表）训练学生模型做序贯规划，而非端到端回归。可证伪预测：高 ruggedness / 高阶上位景观上，序贯路径规划显著胜过回归/贪心。

### 6.2 两篇参考文章的接入
- **Shen 2021**（短读长重建变体 + 逐轮适应度）→ 升级 Protocol A 的适应度重建（解决 17 位点跨 612nt 短读联合定相、手调 fold-change 非校准适应度两个硬伤）。
- **Ranković 2026 / GOLLuM**（PLM 嵌入 + 高斯过程头 + 不确定性校准 BO = 潜空间映射）→ 共享潜空间 + 每靶点特异头，后验均值+方差直接主动提序列；比传统 BO 少 40% 实验。

### 6.3 三层景观方案
- **(A) 经验景观**：每靶点一张，17 位点基因型 + 适应度，Hamming-1 连边。
- **(B) 潜空间景观**：多任务 GP 建在 ESM2 嵌入上 → **共享成分（共同进化景观）+ 分子特异残差（各自景观）**。
- **(C) 可验证路径推理**：在景观上做 WT→目标多突变体的可达路径 + 逐步状态追踪，checker 逐跳校验。

### 6.4 互验设计
- 留一靶点 / 留后期轮次 → 预测 vs 师兄真实进化序列比 precision@k / 路径召回 / 突变共现。
- 零样本迁移新小分子 → top-k 序列 → 一块板（档1）确认。
- **Q164R 作为"模型能否外推到训练分布外未见替换"的硬测试**。

## 10. 需注意的点（踩坑台账，勿重蹈）

> 这些是把乌龙拦在管线里的检查项，**不展开过程**，只记结论性注意点。对应代码门见 §9.7。

1. **突变位点解析必须 `m[1:-1]`**（去首 WT aa + 尾 mut aa = "116"）；**勿用 `m[1:-3]`**（对 "R116Q" 截出 "1" → 所有突变退化成位点 1，制造假特征）。`sequence_gate.py` 有回归测试。
2. **csv mutations 列参考系**：`mutation_activity_full.csv`（建模用）的 0810 克隆 mutations 已含 A11（WT 相对， csv==seq 直接相等）；`mutation_activity_dataset.csv` 的 0810 是 A11 相对（A3="none"）。**建模只用 full.csv，勿混 dataset.csv**。序列关已验证 full.csv 全 28 一致。
3. **"23k/PCA" 不是合并条件**：同一 96 孔板行 A-D=23k-CDCA、E-H=PCA（PPT slide3-4 明示）。建模/报告须拆成两条件（23k-CDCA 6 克隆 / PCA 6 克隆）。
4. **LLDCA = UDCA**（录入错误，熊去氧胆酸，解释其突变最多）；**"DC"/"DCA" = DCA 脱氧胆酸**，是交叉敏感性测试靶点，**不在 28 克隆的三个选择实验里**（那是 7k-LCA/CDCA/23k+PCA）。
5. **三 origin 勿混**：7k-LCA（origin Y159M，但克隆中已 M159Y 回复→实与 CDCA 共享 R116Q+Q164R 骨架）、CDCA（origin R116Q）、23k-CDCA/PCA（origin A11=R116Q+Q136L+Q164R）。**Q136L 是 23k/PCA 的 origin 骨架（非本轮选出的次级突变），勿当"新突变"计入进化深度。**
6. **静态结构 diff 对点突变不敏感**（RMSD 0.06-0.22Å），别构效应须用 ANM 动力学（cross-corr）而非静态坐标 diff。
7. **通用 PLM（ESM2）预测不了特异性驱动突变**（Q164R 排第 2 但净负）→ 须结构+配体条件模型，非纯序列 PLM。
8. **28 样本统计**："翻转 ρ" point 值不可当终值；必报 bootstrap CI（当前全跨 0/极宽→不显著）。跨实验 bootstrap 在小条件集（n=6→6）不可靠，有效 iter 少即标 CI 不可信，不强行出数。**结构权重在看过测试结果后改动须标新探索，不能继续把同一批克隆当验证集。**
9. **旧零样本特征脚本未存盘**，其 ρ 数字（双向 +0.37）不可复算；重建（defensible）得单向 +0.30。**勿再引用旧数字当结论。**
10. **WT 参考序列两版**：`wt_reference_libbackbone.fasta`（旧密码子，匹配 338lib reads，比对专用）与 `wt_reference_altcodon_userpasted.fasta`（蛋白等价但 reads 不匹配库）；突变判定统一在蛋白层面做以绕开歧义。
11. **测序富集 ≠ 活性**：fold-change 来自 PPT 比值，原始荧光（分子/分母）未在盘；把富集命名"活性"前须保留投入池/筛后计数/重复的不确定性（Enrich2 口径区分计数/富集/误差）。
12. **slide3/slide4 fold 矩阵在 PPT 提取 JSON 里逐数字相同**（7kLCA_slide3 ≡ CDCA_slide3）→ 推测是"同板克隆对两胆酸的响应"，但需师兄确认两 slide 真实含义，勿默认。
