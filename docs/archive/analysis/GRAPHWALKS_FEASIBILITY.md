# 338lib 真实选择轮次能否支撑蛋白进化 GraphWalks — 可行性评估

> 2026-09-14。老师提的下一步问题:"实测的选择轮次或亲子谱系,能否支撑一个真正的蛋白进化 GraphWalks 任务?" 本文件基于磁盘核实数据回答。结构预测器支线(LacI ESMFold)已诚实收束,不影响本评估。

## 一句话结论
**有真实选择轮次数据(5 轮 NGS、176k 变体、204aa、逐轮富集适应度),比 Meger 的 ASR 推断树(1158 变体/144 边)好两个数量级。但因是 17 位点饱和组合库,WT 和单突变体不存在,Hamming-1 邻接稀疏(0.63 边/变体),且无直接父母→子代配对——做"真进化 GraphWalks"需要把边的定义从 Hamming-1 邻接换成富集轨迹/可达路径,且仍需师兄补 lib0 基线。当前可做"景观级 + 可达路径推理",做不了"逐代真谱系 GraphWalks"。**

| 项 | 值 |

## 关键限制(决定能否做"真进化 GraphWalks")

### 限制1(致命):WT/单突变体不存在 → Hamming-1 邻接稀疏
- 17 位点饱和库,变体都嵌在 9-10 突变背景里。
- Hamming-1 边实测:51,739 干净变体(n_mut≤17,≥2 轮)只 32,583 边,**0.63 边/变体**,度中位 1,18,343 孤立点,最大分量仅 49 节点。
- 对比:Meger 0.12 边/变体(5× 稠密),但绝对值仍稀疏。原因:变体都带 9-10 突变,两变体恰好差 1 个突变的概率极低(17C9≈24k 组合,邻居稀疏)。
- **含义**:GraphWalks 要求的"稠密可达图 + 前沿扩展"在 Hamming-1 上不可达。

### 限制2:无直接父母→子代配对
- NGS 给每变体每轮**频率**,不给"变体 A 在 round2 变成变体 B"的克隆级谱系。
- 用 Hamming-1 当边仍是**分析者构造的邻接**,不是真实观测的进化路径(老师明确批评过这点)。
- 真正的亲子谱系需要:克隆测序追踪或谱系 barcoding —— 本数据没有。

### 限制3:lib0 未测序
- 起始随机池缺失,富集基线用 lib1(最早轮),适应度非严格 round-0 基线。
- 师兄补测 lib0 才有真基线。

## 可做的(诚实,不夸大)
1. **景观级建模**:109k 变体 + 逐轮富集适应度,做 fitness landscape、上位感知、潜空间(GOLLuM/PCA)。RESULTS.md 已做 fig1-4,PCA 仅解释 16.1% 方差 → 高维 rugged 景观,上位感知路线对路。
2. **可达路径推理**(非 Hamming-1):边定义为"富集轨迹相似/相邻突变阶",做变体→变体的富集转移图,看高适应度变体的可达路径是否破 greedy myopic ascent。这是 GraphWalks future-work 的真命题,但需重新定义边(非 Hamming-1)。
3. **加性/上位分解**:用 6840 可靠变体做 17 位点的上位效应分解(因 WT/单突变不存在,需高阶回归或潜空间方法)。

## 做不了的(诚实)
- 逐代真谱系 GraphWalks(无父母→子代配对)
- Hamming-1 稠密可达图(WT/单突变不存在,边稀疏)
- 真 round-0 基线适应度(lib0 缺)

## Go / No-Go
**有条件 GO —— 景观级 + 富集轨迹可达路径,非逐代真谱系。**

要做成真 GraphWalks,需补的实验/数据(按优先级):
1. **lib0 补测**(师兄):起始随机池 → 真 round-0 富集基线。**这是补实验的第一优先级。**
2. **边定义重设计**:从 Hamming-1 邻接换成"富集轨迹相邻 + 突变阶相邻"的混合边,做可达路径图(非邻接图)。可在现有数据上做,不需新实验。
3. **(可选,湿实验)谱系 barcoding**:若要做逐代真谱系,需新一轮带 barcode 的克隆追踪实验——成本高,不在现有数据内。
4. **(可选)双向筛选/多小分子**:RESULTS.md 待确认提到等双向筛选数据 → 可做多任务景观。
