# 突变→活性预测：零样本跨蛋白泛化 + 物理推理链

日期 2026-09-13。`work/results/mutation_activity_full.csv` + `clone_esm2_3B_emb.npy`。

## 核心论点

**Baseline 越低越好**——ESM2 单独跨实验 ρ=-0.37（负相关），不是失败是**预期内的正确结果**。28 个克隆、3 个实验，纯序列 PLM 不可能跨胆酸泛化。Baseline 低 = 结构+配体特征提升空间大 = 贡献明显。

**有一点泛化信号 = 巨大贡献**——28 个样本的极端数据稀缺下，结构+胆酸特征把 7k-LCA↔CDCA 从 ρ=-0.37 翻转到 +0.37。**方向翻转本身是强信号**：模型学到的不是统计相关，而是"配体结构→别构通路→特异突变"的物理因果链。

## 物理推理链（每步对应一个物理约束）

### 约束 1: 别构远程耦合
- **实测**: pocket(Q164)↔HTH(35) = 32.7Å（自身 ESMFold, pLDDT 94.3）
- **实测**: ANM cross-corr = -0.394（显著别构）
- **物理**: 小分子结合 LBD 口袋 → 构象变化 → 33Å 外 HTH 取向改变 → DNA 结合变化
- **模型含义**: 位点须用别构耦合分(ANM)加权，不能等权
- **特征**: `allosteric_score`（ANM cross-corr + 口袋距离）

### 约束 2: 配体结构差异决定突变位点
- **实测**: 7位修饰组 vs C23组 突变位点**零重叠**
- **物理**: 胆酸的化学修饰位置(7位环B vs 侧链C23) → 口袋不同接触面 → 进化动用不同位点
- **模型含义**: 须用胆酸结构作为靶点条件，不能跨胆酸等权
- **特征**: 胆酸 Morgan 指纹(带手性) → Tanimoto 相似度

### 约束 3: 静态结构对点突变不敏感
- **实测**: Q164R/R116Q vs WT RMSD = 0.06-0.22Å
- **物理**: 别构效应不在静态结构 diff，在动力学涨落
- **模型含义**: 须用动力学(ANM 慢模式)而非静态坐标
- **特征**: ANM cross-corr（动态耦合），不用 RMSD

### 约束 4: 通用 PLM 预测不了特异性突变
- **实测**: ESM2 零样本 Q164R 排第 2 但净负；跨实验 ρ=-0.37
- **物理**: "不破坏蛋白" ≠ "对该胆酸响应"——特异性突变对通用适合度"坏"但对特定功能"好"
- **模型含义**: 须用结构+配体条件，不能只用序列
- **特征**: ESM2 嵌入(通用先验) + 结构(别构) + 胆酸(配体) 三路融合

## 每个小分子的进化结果（相对野生型带多少突变）

28 克隆**全部含 R116Q**（6 靶点 100% 固定的骨架起点突变，骨架自带、非本轮进化选出）。此外 Q164R 在 7k-LCA/CDCA/23kPCA 三组分别 7/7、6/9、12/12 几乎全固定；**Q136L 在 23k/PCA 12/12 全固定**（A11 origin 标志，见下），在 CDCA 仅 1/9、7k-LCA 0/7。所以"相对 WT 的突变数"要分三层：含全部突变的 n_mut、去 R116Q、去全部 origin 骨架（R116Q+Q164R+该组 100% 固定的 Q136L）后**真正本轮进化选出的突变**。

| 实验(小分子) | 克隆数 | n_mut(全含) 均值/中位/范围 | 去 R116Q 均值 | **去全部 origin 骨架后真实突变** 均值/范围 |
|---|---|---|---|---|
| 7k-LCA | 7 | 2.86 / 3 / 2–4 | 1.86 | **0.86 / 0–2** |
| CDCA | 9 | 2.11 / 2 / 1–3 | 1.11 | **0.44 / 0–1** |
| 23k/PCA | 12 | 3.25 / 3 / 3–4 | 2.25 | **0.25 / 0–1** |

**一句话**：相对野生型，每个小分子的赢家克隆名义上带 1–4 个突变，但扣掉 origin 骨架（R116Q+Q164R+23kPCA 的 Q136L）后，**真正本轮进化选出的新增突变只有 0–2 个**（7k-LCA 0.86、CDCA 0.44、23k/PCA 0.25 均值）——中位数基本 **0–1 个新增点突变**就能拿到 fold-change 3–24 倍的胆酸响应。极轻量进化：origin 骨架（尤其 Q164R 胆酸响应开关）承担主要响应，1 个左右新增突变做特异微调即可把 aTF 改造成对特定胆酸响应的传感器。

**三点观察（支撑约束 2「配体结构决定位点」）**：

1. **真实突变数梯度是 23k/PCA < CDCA < 7k-LCA（与 fc 高低同向）**：去 origin 骨架后 23k/PCA 仅 0.25、CDCA 0.44、7k-LCA 0.86。之前"23k/PCA 名义 n_mut 最高(3.25)"是**被 origin 骨架里多出的 Q136L 污染的假梯度**——23k/PCA 进化其实最浅（12 条大多只有 origin 骨架、几乎无新增选择突变），故其 fc 最低（均值 ~4.1，远低于 7k-LCA ~13、CDCA ~7.3）。**进化深度与响应强度同向**，不是"突变越多越好"。

2. **Q164R 是三实验共享响应开关**（7k-LCA 7/7、CDCA 6/9、23k/PCA 12/12 全带），与 6 靶点全景"Q164R 全共享胆酸响应开关"一致。扣掉 origin 骨架后，几乎所有克隆 = Q164R(骨架) + 0–1 个特异次级突变。

3. **特异次级突变位点和胆酸化学修饰位置同向**（去掉骨架 R116Q+Q164R+Q136L 后剩的；注意 Q136L 在 23k/PCA 是 origin 骨架 12/12 固定、不算次级，见下）：
   - **7k-LCA**（7位修饰组）：D176N(3/7)、A121T、E113K、H174Y — 位点 {174,176}
   - **CDCA**（基准骨架）：I73N(2/9)、Y129H — 位点 {73}
   - **23k/PCA**（C23 侧链组）：E143D(2/12)、L177S(1/12) — 位点 {143,177}

   这正好对上约束 2 的 7 位修饰组 vs C23 组**零重叠**：突变动用的位点跟着胆酸化学修饰位置走（7 位环 B → 174/176；侧链 C23 → 143/177），是"配体结构→特异突变"的直接实测证据。

   **Q136L 的双重身份（重要）**：它在 **23k/PCA 12/12 全固定** = A11 origin（R116Q+Q136L+Q164R）的骨架标志，和 R116Q 一样是 origin 自带、非本轮选出，**不算次级**；在 **CDCA 仅 1/9**（A1 克隆，且该克隆 fc=3.85 是 CDCA 最低档之一）；在 **7k-LCA 0/7**。即 Q136L 是 origin 分层标记——CDCA/7k-LCA 用简单 origin（无 Q136L），23k/PCA 用 A11 origin（带 Q136L）。这正落点是跨实验退步的根源：CDCA 组唯一带 Q136L 的 A1 fc 偏低，与 23k/PCA 整体 fc 偏低一致——**A11 origin/Q136L 系统性拉低响应**，是 23k/PCA 跨实验退步的实测落点。

4. **fold-change 与突变数不单调**（非"突变越多响应越强"）：7k-LCA 的 B9(2 突变) fc=23.8 最高、A8(4 突变) fc=3.55 反低；CDCA 的 E2(1 突变) fc=5.48 vs A1(3 突变) fc=3.85。aTF 进化是稀疏信号、特定组合驱动，呼应"28 样本信号密度高、物理因果链真实"。

逐克隆明细见 `mutation_activity_full.csv`（列：clone, exp, mutations, n_mut, fold_change, seq）。

## 诚实评估

### 信号真实
- 7k-LCA↔CDCA 翻转（-0.37→+0.37）**不是偶然**——双向都翻转，且对应物理约束 1+2（别构+配体结构）。
- 28 样本能到 ρ=0.37，单位数据信号密度远高于 AncLacI 参照（1158 变体 ρ=0.76）。

### 退步有物理解释
- 23k/PCA 退步：origin 不同（A11=R116Q+Q136L+Q164R vs 7k-LCA/CDCA 的简单 origin），特征分布偏移。
- **不是方法错，是训练数据不足 + origin 覆盖不全**——这正是"数据稀缺下的诚实结论"。

### 贡献定位
1. **首次在 aTF 生物传感器上做零样本跨蛋白(跨胆酸)活性预测**，用物理可解释的结构+配体特征。
2. **四条物理约束→四个特征→跨实验翻转**，不是黑箱。
3. **Baseline 低(ESM2 -0.37) + 加特征翻转(+0.37) = 贡献清晰**：结构+配体条件是泛化的关键，纯序列不够。
4. **28 样本能出信号 = 信号密度高 = 物理因果链真实**——如果只是统计噪声，28 样本翻不了。
