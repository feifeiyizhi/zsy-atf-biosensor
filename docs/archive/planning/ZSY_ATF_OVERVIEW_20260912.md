## 一、一句话概览

我们拿到了一个 TetR 家族 aTF（204 aa）的两类真实进化测序数据——**① DNA 结合负筛的 5 轮富集文库（338lib，17 位点饱和突变库）**和 **② 6 种胆酸小分子的响应筛选（纳米孔 pool）**——把它们各自重建成"基因型→适应度"景观，并结合结构（同源建模 + 别构动力学）+ ESM2 序列先验，得到一个可解释的结论：

> **Q164R 是 6 种胆酸全部共享的核心响应开关**（落在配体口袋壁，3D 距离配体 = 0 Å），而各胆酸另有自己的靶点特异次级调谐突变。据此我们做出了一个能给下一轮实验推荐突变的打分器。

---

## 二、背景与目标

**aTF 生物传感器**：变构转录因子——小分子配体通过变构调节其 DNA 结合活性。本项目的 TetR 家族 aTF 是一个"小分子诱导的基因表达开关（chemogenetic switch）"：无配体时结合 DNA 抑制目标基因；配体结合后释放 DNA、去抑制。工程目标是造出**响应特定小分子、且 ON/OFF 动态范围可调、配体特异性可控**的开关（用于研究细胞机制、设计工程治疗细胞等）。

**WT 结构（204 aa）**：

- **DBD**（N 端 ~aa1–47，翼状 HTH，α3 识别螺旋 ~aa35–45 直接读 DNA 大沟）
- **linker**（~aa47–52，别构偶联铰链）
- **LBD**（C 端 ~aa48–210，全螺旋束，配体口袋核心 ~aa100–180）

**17 位点饱和突变库**：N66·V69·Y75·E94·Y102·A107·V111·I125·I128·Y129·A133·Y159·S161·F163·Q164·W169·P170。**全部落在 LBD，无一碰 DNA 结合螺旋**——即文库通过 LBD 构象的别构调节来改变 DNA 结合，而非直接改识别螺旋。

**张老师命题的五要素**：算法突破 + 构建 landscape + 潜空间映射 + AI 预测与进化数据互验 + 对其他小分子做序列预测。

## 三、两类真实数据

### 3.1 DNA 结合负筛文库（338lib，实验 A）

- 5 轮逐轮正向筛选（lib1→lib5），选择压力 = DNA 结合差的被淘汰 → 富集出有 DNA 结合能力的变体。
- Illumina 双端 250 bp，重叠 145 bp，扩增子 ref[175:530] = 355 nt。
- 每 lib 约 190–205 万 reads，保留率 ~97%。
- 处理脚本 `build_landscape.py`（纯 Python，43 秒跑完全 5 lib）：合并重建全长基因（612 nt）→ 翻译 204 aa → 定位突变 → 逐轮频率 → 适应度 = log2 逐轮频率对轮次的加权线性斜率（斜率 >0 = 随轮次富集 = DNA 结合更好）。
- **干净变体 109,134；可靠子集 6,840**。WT/单突变几乎不存在，突变阶数集中 **9–10/17** → 是**高阶组合库**。PCA 2D 仅解释 16.1% → 景观高维、rugged。
- **lib0（起始随机池）未测序**，目前用 lib1 代基线（待补测，见卡点）。

### 3.2 6 种胆酸响应筛选（实验 B，纳米孔 pool）

- 6 靶点：**CDCA / PCA / 7K-LCA / 23K-CDCA / LCA / LLDCA**（原计划双向筛选，现重定位为"顺序两步"的第二步 = 参考/ground-truth）。
- 每靶点纳米孔 fastq + bam + Sanger ab1 + 组装共识 + 差异统计 xlsx，扩增子 646 bp（基因区 612 bp）。
- 处理脚本 `six_target_landscape.py`：每条 read 锚点定位基因区 → 翻译 → 过滤移码/终止子/长度不符 → 蛋白级 diff → 频率化压噪（每位点非-WT 比例 ≥10% 视为显著）。
- 各靶点有效 reads（ok）：CDCA 14,262 / PCA 8,723 / 7K-LCA 18,531 / 23K-CDCA 21,242 / LCA 11,382 / LLDCA 13,719。

> **数据诚实边界**：负筛 lib0 缺失（用 lib1 代基线）；富集 = selection proxy，不等于生化 fitness；纳米孔为单克隆/pool 混合，频率化后按 ≥10% 阈值判定以压噪。

## 四、核心结果

### 4.1 【最新，2026-09-12】6 靶点全景：Q164R 是 universal 胆酸响应开关

（R116Q 在 6 靶点均 100% 固定 = 骨架起点自带、非筛选驱动，已剔除。）

| 突变                | CDCA  | PCA   | 7K-LCA          | 23K-CDCA | LCA   | LLDCA               | 性质                               |
| ------------------- | ----- | ----- | --------------- | -------- | ----- | ------------------- | ---------------------------------- |
| **Q164R**     | 16.6% | 99.6% | 99.4%           | 99.8%    | 99.2% | 98.2%               | **6 靶点全共享**（核心开关） |
| I73N                | 26.6% | –    | –              | –       | –    | –                  | CDCA 特异                          |
| L177S               | –    | 10.3% | –              | –       | –    | –                  | PCA 特异                           |
| D176N               | –    | –    | **73.3%** | –       | –    | –                  | 7K-LCA 特异（高频）                |
| E143D               | –    | –    | –              | 28.3%    | –    | –                  | 23K-CDCA 特异                      |
| I64T / K93I / P152L | –    | –    | –              | –       | –    | 16.1 / 10.3 / 16.4% | LLDCA 特异（多突变）               |

**解读**：

1. **Q164R = 6 种结构不同的胆酸的通用突变**（除 CDCA 仅 16% 亚群外，其余 98–99.8% 全固定）。Q164 在 17 设计位点内、且是 LBD 配体口袋壁（3D 距离配体 = 0 Å）→ 直接决定胆酸识别特异性，跨靶点一致。
2. **各靶点有特异的次级调谐突变**（亚群，多落在口袋外的 LBD 区）：7K-LCA 的 D176N(73%)、23K-CDCA 的 E143D(28%)、LLDCA 的多突变、CDCA 的 I73N。这些是靶点特异的微调，调别构动力学/特异性。
3. **LCA 最"纯"**（仅 Q164R），**LLDCA 最复杂**（4 突变）。
4. **与负筛景观的关系**：Q164R 在 338lib 负筛库里几乎没被采样（5/109,134），却被 6 胆酸全部固定 → 负筛（DNA 结合）与胆酸响应（小分子）是**两张互补的景观**，靠负筛外推预测不了 Q164R；但 Q164 是同时影响两者的**多效位点（pleiotropy）**，是连接两张景观的少数真实锚点。

### 4.2 结构线（已完成，支撑"必须基于结构"）

- **17 位点结构定位**：DBD 内 0/17，LBD 内 17/17，口袋核心区 aa100–180 占 13/17。
- **同源结构**：BLAST 找到最近 TetR 同源 **3CDL**（identity 33.5%），17 位点 16/17 可映射。因本机装不动 ESMFold/AF2（缺 openfold/GPU/MSA），用 3CDL + ProDy ANM 兜底。
- **别构耦合（ANM）**：扰动配体口袋 Q164 → HTH α3 识别螺旋响应 0.05–0.08（超背景）→ **证实 pocket↔HTH 长程别构通道存在**。
- **3D 距离精修**：口袋↔HTH = 33.3 Å（真长程别构）；直接围配体的口袋壁 = **S161(5.1Å) / F163(3.8Å) / Q164(0Å)**（解释 Q164R 定特异性、S161→A/F163→M 负筛高频）；别构中继候选 = Y102。
- **ESM2 零样本**：给全 20 AA 突变先验，能外推到未测替换；但**在 164 位把 R 排第 2 仍是净负** → **通用 PLM 预测不了"特异性驱动突变"**（这类突变对通用折叠"坏"、对特定小分子功能"好"）⇒ 特异性预测**必须**靠结构 + 功能条件模型。这是本项目建模路线的实证支撑。

### 4.3 参照系统 AncLacI（同超家族，端到端验证 v2 建模可行）

基于 Meger 2024（Cell Systems，LacI/GalR DBD 景观，同 DBD+LBD 架构、同小分子别构调 DNA 结合）：

- **序列→unseen 突变体 DNA 结合活性**：稠密区 GBM Spearman ρ **0.76**（预测好），稀疏区 ρ 0.31 但功能变体 top-k 命中率 0.91–1.00。
- **序列→±小分子别构效应（v2 核心）**：别构 shift（IPTG 饱和 − 无）Spearman **0.72** ⭐（小分子有无的 DNA 结合变化可预测）。
- **边界**：EC50（精确效力）预测不了（n=54 太小）；跨序列区不互迁（LGF→DMS ρ 0.20–0.26，与本项目负筛↔胆酸不相交一致）。

### 4.4 【最新，2026-09-12】突变推荐器（recommender v1→v4）

脚本 `mutation_recommender_v4.py`。对每个胆酸靶点、全 204 位点打分，给出两类推荐：

- **借鉴型（cross-target transfer）**：某靶点已验证的次级突变借到别的靶点（如 D176N 从 7K-LCA 的 73% 借给其他靶点）。
- **全新/探索型**：没靶点试过、但**别构相关（ANM+口袋 3D 距离）+ ESM2 可容忍**的位点 AA。
- 打分 = 借鉴信号 / 别构分 / ESM2 先验的加权组合（排除已固定的 R116Q/Q164R 两个骨架位）。
- 内置 **LOTO 验证**（留一靶点，看能否用其余 5 靶点召回被留出靶点的真实次级）——注意各靶点次级多为**特异**（D176N 只在 7K-LCA、E143D 只在 23K-CDCA），因此"跨靶点借鉴"能召回的比例有限，这本身也印证了"Q164R 通用、次级特异"的结论。
- 产物：每靶点 `{target}_rec_v4.csv` + 汇总 `all_rec_v4_top10.csv`（示例：D176N 因 7K-LCA 高频被借给多个靶点，得分居前）。

> **说明**：推荐器目前是 in-silico 打分（结构先验 + 已测数据），推荐的新突变尚未湿实验验证，属"下一轮候选"，不是已证结论。

### 4.5 【最新，2026-09-14】真实进化图 GraphWalks：破 greedy 命题成立(信号温和)

回到张老师最初的算法命题——**可验证过程监督 / GraphWalks 式路径推理**——核心问题是：**这批真实进化数据里，是否存在"贪心（每步选局部最优）会失败、需要前瞻（lookahead）才能到达高峰"的路径？** 若有，就是过程监督的真实训练/测试底物。

**先破一个诱惑**：直接用"序列差 1 突变（Hamming-1）"当边是**分析者构造的邻接**，不是真实进化路径。且 338lib 是 17 位点高阶库（变体都带 9-10 突变），Hamming-1 邻接极稀疏（51,739 变体仅 0.63 边/变体，18,343 孤立点）——不能支撑 GraphWalks。

**正确的边 = 突变阶相邻（nested subset+1）**：child 的突变集 ⊃ parent 且恰多一个突变（=定向进化真实的"逐步累积突变"步）。用 6840 可靠变体 + 真实富集适应度（fitness_slope）构有向图：

| 指标                   | 值                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------- |
| 节点 / 真进化边        | 6840 / 9068                                                                            |
| 连通节点               | **80.8%**（vs Hamming-1 一堆孤立点）                                             |
| 最长进化链（多跳路径） | 11 跳                                                                                  |
| 进化步下坡(df<0)比例   | **51.1%**（单步贪心信号弱）                                                      |
| 破 greedy 谷节点       | **862**（fit 低于所有 parent → 贪心停步，但过谷后到达超越所有 parent 的更高峰） |

**破 greedy 案例**（先降后升，贪心拿不到）：`parent 0.533 --Y159W--> 谷 0.466(降0.067) --Y129F--> 0.85(升0.385)`。

**置换检验（诚实强度）**：打乱 fitness 标签 500 次，随机期望 802.5±26.5；观测 862，**z=2.25, p=0.012 —— 超随机但仅 +7%（约 59 个净谷节点）**。→ **过谷路径真实存在，但"破 greedy"强度温和**，不是"贪心大面积失败"。诚实表述：这是 GraphWalks 的**可用底物**，信号真实但需补 lib0 + 更严适应度后重估强度，并精选强 valley 子集（降幅大、升幅大）做高信噪任务。

**关键定位**：并行推进的 LacI 结构预测器支线（用 ESMFold 结构特征升级活性预测器）已**触发停止条件收束**（模型对突变有局部响应，但结构特征在防泄漏验证下不提供活性预测增益，增量 ΔR²≈−0.02、CI 跨零）。**但这不等于蛋白 GraphWalks 方向失败**——真实进化路径 + 活性景观的数据任务（本节 338lib 进化图）给出了正向证据。两条线要分开讲：结构特征升级预测器 = 收束；真实进化图上的过程监督 = 活的、可继续。

## 五、结论边界（诚实）

1. v2 路线在参照系统 **LacI/IPTG 上端到端跑通**：序列→DNA 结合活性（稠密区 ρ 0.76）+ 序列→±小分子别构效应（shift 0.72）。
2. **EC50 预测不了**（n=54 太小，需更多数据/结构）。
3. **通用 PLM 零样本预测不了特异性驱动突变**（ESM2 对 Q164R 净负）→ 需结构+功能条件模型。
4. **跨区不迁移**（景观区域特异性坐实；负筛↔胆酸序列空间几乎不相交）。
5. **密度决定质量**（稠密区预测远好于稀疏区）。
6. 6 靶点结论（Q164R 通用 / 次级特异）稳固；推荐器新突变**待湿实验验证**。
7. **【09-14】真实进化图破 greedy 命题成立但温和**：突变阶相邻边构图 80.8% 连通、862 破 greedy 谷节点，但置换检验 z=2.25/p=0.012 仅超随机 +7% → 是 GraphWalks 可用底物，非"贪心大面积失败"的强证据；需补 lib0 + 精选强 valley 子集提信噪。
8. **【09-14】结构特征升级预测器这条支线收束（负结论）**：LacI ESMFold 结构特征对突变有局部响应，但防泄漏验证下不提供活性预测增益（ΔR²≈−0.02，CI 跨零）。与"进化图过程监督（活）"分开讲，不是整个方向失败。
