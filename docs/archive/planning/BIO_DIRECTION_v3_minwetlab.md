# v3：最小化湿实验的方案设计

日期 2026-08-16。约束：湿实验工作尽可能小。承接 BIO_DIRECTION_v2.md。

---

## 0. 核心原则：把"验证"和"湿实验"解耦

v2 的关键洞察在这里被用到极致：**我们方法的卖点就是"可验证"——而验证器是已测好的适应度景观，不是湿实验。** 湿实验唯一不可替代的作用是"前瞻性地造出一个此前没人测过的、更好的蛋白"。除此之外的所有科学主张，都能在**真实生物数据上、纯 in-silico、精确可验证**地完成。

所以策略：把论文的**证明重心全部压到 in-silico 层**，湿实验缩到"一个确认性实验"，而且把这个"少湿实验"本身变成**样本效率的正面证据**。

---

## 1. 三档湿实验规模（从零到最小，按需上）

| 档 | 湿实验量 | 能支撑的主张 | 适配 venue |
|---|---|---|---|
| **档 0：零湿实验** | 0 | 在真实 DMS 景观上，路径规划推理 > EVOLVEpro/MULTI-evolve 回归；可验证过程监督 > 自由CoT > 答案级；机制预测（process-acc 先崩、序贯>回归的 ruggedness 分界）全部成立 | ML 顶会 / ML-for-science（NeurIPS, ICLR, ICML, Nature Machine Intelligence） |
| **档 1：单轮确认（推荐）** | 1 蛋白 × 1 轮 × ~10–24 变体 × 1 块板 | 上面全部 + "模型规划的路径终点是**真实新蛋白**，活性超 WT 且超 baseline 的 pick" | 跨学科顶刊可投（Nat Methods / Nat Comms / Science 系的算法向） |
| **档 2：小 campaign** | 1 蛋白 × 2–3 轮 × 每轮 ~10–20 变体 | 上面全部 + "隐图主动探索闭环在真实湿实验里比 EVOLVEpro 更省样本" | 纯实验旗舰（Science/Nature 正刊）才需要 |

**建议默认做到档 1。** 档 0 就已经是一篇完整的 ML-for-bio 论文；档 1 只加"一块板"就拿到"造出真实更好蛋白"的印章；档 2 只有在冲实验向正刊、且实验室富余时才做。

## 2. 关键技巧：用"已测全景观"当**模拟湿实验 oracle**，把 Layer 3 也搬进 in-silico

v2 里最贵的是 Layer 3（隐图 + 多轮湿实验的主动探索）。**它可以完全不花湿实验就验证**：

- 取一张**组合完备**的 DMS 景观（如 GB1 4 位点 ~15 万变体全测）。
- **假装它是隐图**：模型初始只看到 WT 附近少数点，每次"查询"一个变体，就从**已测好的真实数据**里返回该点活性（reveal-on-query）。
- 于是"隐图上的主动图探索 + 逐轮重规划"整个闭环，在**真实生物测量数据**上跑，精确可验证，**零湿实验**。
- 指标：达到目标活性所需的**查询数（=湿实验次数）**，对比 EVOLVEpro 的 active learning。**预测：路径推理更省查询** → 这既验证了算法，又直接量化了"我们更省湿实验"。

**含义**：档 0 就能把"主动探索更省样本"这个 Layer 3 的核心主张证完。真湿实验（档 1）只需最后补一个"prospective 单轮确认"，证明模拟 oracle 的结论在真实分子上成立。

## 3. 档 1 的最小湿实验，具体怎么设计（把成本压到一块板）

**选蛋白**：直接用**实验室已有表达+活性 assay、且 630 平台已跑通**的那个蛋白（marginal 成本≈0，无需新建体系）。不要为论文新起一个体系。
- 从 zsyPDF 反推的候选：APEX（过氧化物酶，比色/荧光 assay 简单）、某 Cas 类、某工程酶——**以实验室现成 assay 为准**。

**单轮设计（无迭代）**：
1. 模型在该蛋白的**现有数据**（哪怕只有单/双突变的少量点，或 PLM zero-shot 先验）上，规划出可达路径，输出**路径终点的 top-k 多突变体**（k≈8–16）。
2. 同一预算下让 **EVOLVEpro/MULTI-evolve baseline** 也各出 top-k。
3. 合并去重，**一块板**（≤24 或 ≤48 孔，含 WT 与阴性对照）**一次性合成+测活性**。
4. 读数即结论：我们的路径终点活性 > WT，且 ≥ baseline 的最佳 pick。

**为什么这就够**：
- 造出真实更好蛋白（前瞻性）✔
- 与 baseline 头对头（公平对照）✔
- 单轮、无迭代 → 无多轮试剂/时间成本 ✔
- 一块板 → 一次上样、一次检测，正好落在 630 平台"单机基础版"脚本（孔板上料→启动）✔

**把约束变卖点**：论文明确报"我们只用 N 次湿实验测量就拿到活性增益，EVOLVEpro 达到同等增益需 M≫N 次"——**少湿实验 = 样本效率贡献**，不是妥协。
