## 结论(诚实)

1. **三版位点算法完全一致**(seq/csv_raw/csv_unified 的 LOO 与跨实验 ρ 全同)。证明:对 7k-LCA/CDCA 克隆,csv mutations(nonsyn)==seq diff(均 WT 相对),之前差异纯是 `m[1:-3]` 解析 bug(把 R116Q→位1);0810 的 A11 补不补对跨实验 ρ 无实质影响(ESM2+胆酸主导,位点特征贡献小)。→ **问题4(参考系不一致)不实质改变零样本 ρ**,"23k 退步"主要是 origin 偏移(数据层),非特征偏差。

2. **LOO 复现成功**:ESM2-only −0.112(旧表 −0.999=PCA+Ridge 过拟合假象,非模型能力)、+结构+胆酸 0.404(旧0.402✓)、+onehot 0.414(旧0.406✓)。→ 同池内信号 robust。

3. **"双向翻转"不复现(头条 claim 削弱)**:旧表称 7k-LCA↔CDCA 双向 −0.37→+0.37/+0.36。重建:**CDCA→7k-LCA −0.371→+0.296(翻✓,但幅度+0.30非+0.36);7k-LCA→CDCA −0.366→−0.070(不翻,仍负)**。只有单向翻,非双向对称。

4. **23k/PCA 加特征普遍退步**(ESM2-only 多对 +0.2~+0.65,加结构+胆酸后大多转负)——与旧表"23k/PCA 退步"一致,robust。n=6→6 噪声大,不可单独引用。

5. **诚实边界**:本重建非与原脚本同构(原脚本未存盘)。struct=ANM耦合均值/绝对和/设计位命中/n_mut;bile=Morgan1024bit;onehot=204维。若原脚本用了不同 struct/bile 定义,**可能**原 +0.37 双向是其特定实现的产物。本重建证明:**用 defensible 特征定义,双向翻转不复现,仅单向**。→ 零样本跨胆酸泛化的头条结论应降级为"单向(CDCA→7k-LCA)翻转 +0.30,反向不翻",且需 bootstrap CI(28样本)。


## 对 zero_shot_cross_protein.md 的修正建议

- "双向翻转"→"单向翻转(CDCA→7k-LCA −0.37→+0.30);7k-LCA→CDCA 不翻(−0.07)"。
